# 🛍️ Shopora — E-Commerce Web Application

A modern **Flask-based e-commerce web application** designed to provide a complete online shopping experience with product browsing, user accounts, cart management, wishlists, orders, reviews, and profile management.

> **Project:** Shopora E-Commerce Project  
> **Backend:** Python + Flask  
> **Database:** SQLite  
> **Frontend:** HTML, CSS, JavaScript  
> **Status:** 🚧 Academic / Development Project

---

## ✨ Features

### 🛒 Shopping
- Browse available products
- View detailed product information
- Add products to the shopping cart
- Manage cart items
- Add products to a wishlist

### 👤 User Management
- User registration and login
- User profile management
- User-specific cart and wishlist
- Order history

### 📦 Orders
- Place orders
- View previous orders
- View individual order details

### ⭐ Reviews
- Submit product reviews
- Product ratings
- Review approval support

### 🎨 User Interface
- Responsive web pages
- Product listing and product-detail pages
- Dedicated pages for cart, wishlist, profile, and orders

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/Bhuvaneswari30/my-project.git
cd my-project
```

### 2. Create a virtual environment

Windows:

```bash
python -m venv venv
```

Activate it:

```bash
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open the application

Open the local URL shown in the terminal, commonly:

```text
http://127.0.0.1:5000/
```
